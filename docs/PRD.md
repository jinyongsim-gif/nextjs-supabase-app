# Gather PRD (Product Requirements Document)

> 일회성 이벤트 관리 플랫폼 MVP
> 상세 버전(페이지별 명세, 데이터 모델, Sprint 계획 등)은 [PRD.old.md](./PRD.old.md) 참조

## 1. 프로젝트 개요

### 1.1 목적

초대 링크 하나로 생일 파티, 워크샵, 세미나 등 **5~30명 규모의 일회성 이벤트**를 간편하게 만들고 관리할 수 있는 모바일 퍼스트 웹 플랫폼입니다.

기존 방식(단톡방 공지, 구글 폼, 수기 취합)은 참여자 파악이 번거롭고 정보가 흩어지는 문제가 있습니다. Gather는 이벤트 생성 → 링크 공유 → 참여 확인을 하나의 흐름으로 제공합니다.

### 1.2 목표

| 구분 | 목표 |
|------|------|
| **사용자 경험** | 이벤트 생성부터 초대 링크 공유까지 3분 이내, 참여자는 로그인 포함 3번의 탭으로 참여 |
| **핵심 가치** | 가입 장벽 최소화 (Google 로그인), 참여자 현황 실시간 확인 |
| **운영** | 관리자가 이벤트·사용자·통계를 데스크톱 대시보드에서 관리 |
| **확장성** | MVP 이후 정산, 카풀, 알림 기능으로 확장 가능한 구조 |

### 1.3 대상 사용자

| 역할 | 설명 | 주 사용 환경 |
|------|------|-------------|
| **주최자** | 이벤트를 만들고 초대 링크를 공유하는 사용자 | 모바일 |
| **참여자** | 초대 링크로 이벤트에 참여하는 사용자 | 모바일 |
| **관리자** | 플랫폼 전체를 모니터링·관리하는 운영자 (`role: admin`) | 데스크톱 |

### 1.4 성공 지표 (MVP 출시 후 1개월)

| 지표 | 목표값 |
|------|--------|
| 주간 생성 이벤트 수 | 50개/주 |
| 월간 활성 사용자 (MAU) | 200명 |
| 초대 링크 → 회원가입 전환율 | 70% |
| 이벤트당 평균 참여자 수 | 8명 |
| 7일 이내 재방문율 | 40% |

## 2. 핵심 기능 목록

### 2.1 MVP 핵심 기능 (주최자/참여자)

| ID | 기능명 | 설명 |
|----|--------|------|
| F001 | 이벤트 생성 | 제목, 설명, 날짜, 장소, 커버 이미지를 입력해 이벤트 생성 |
| F002 | 초대 링크 자동 생성 | 이벤트 생성 시 고유 초대 코드(`invite_code`) 자동 발급 (예: `/join/abc123`) |
| F003 | 초대 링크 공유 | 카카오톡, 문자, 클립보드 복사로 링크 공유 |
| F004 | 초대 링크 참여 | 링크 클릭 → 이벤트 미리보기 → 로그인 → 자동 참여 |
| F005 | 실시간 참여자 목록 | Supabase Realtime으로 참여자 추가 시 즉시 목록 갱신 |
| F006 | 이벤트 수정/삭제 | 주최자만 이벤트 정보 수정 또는 삭제 가능 |
| F007 | 내 이벤트 목록 | 내가 만든 이벤트 / 내가 참여한 이벤트를 카드 리스트로 조회 |
| F008 | 이벤트 상태 관리 | 날짜 기준 예정 / 진행 중 / 종료 자동 분류 및 필터 |
| F009 | 커버 이미지 업로드 | Supabase Storage 기반 이미지 업로드 |

### 2.2 MVP 지원 기능 (인증/프로필/관리자)

| ID | 기능명 | 설명 |
|----|--------|------|
| F010 | Google OAuth 로그인 | Google 계정으로 회원가입/로그인 (구현 완료) |
| F011 | 사용자 프로필 관리 | 이름, 프로필 사진 등 기본 정보 조회/수정 |
| F012 | 관리자 대시보드 | 오늘/이번 주/이번 달/전체 이벤트·사용자 수 지표 카드 |
| F013 | 이벤트 관리 테이블 | 전체 이벤트 검색, 필터, 삭제 |
| F014 | 사용자 관리 테이블 | 전체 사용자 검색, 필터, 삭제 |
| F015 | 통계 그래프 | 이벤트 생성 추이, 사용자 증가 추이 (최근 7일) |

### 2.3 MVP 이후 (Phase 2)

- **정산 관리**: 정산 항목 생성, N분의 1 자동 계산, 송금 완료 체크
- **카풀 관리**: 운전자 등록, 탑승 신청/배정
- **알림 시스템**: 이메일/푸시 알림, 리마인더
- **이벤트 공지**: 이벤트별 공지사항
- 고급 검색(날짜 범위, 장소), 소셜 기능, 설정(테마·언어·알림)

### 아키텍처 요약

- **Supabase 클라이언트 3종**: Server(`lib/supabase/server.ts`), Client(`lib/supabase/client.ts`), Middleware(`lib/supabase/middleware.ts`)
- **라우트 구성**: 사용자 화면 `app/(mobile)/*`, 관리자 `app/admin/*`, 인증 `app/auth/*`
- **데이터 변경**: Server Actions (`app/actions/*`), 조회는 `lib/data/*`, `lib/queries/*`
